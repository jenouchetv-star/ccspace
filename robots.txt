# Deliberately blocking all crawling for now - this is a prototype (no
# real checkout, legal review still pending) and chikescreativespace.com
# already has a real, unrelated live site, so two different search
# results for the same business would confuse real customers. The
# noindex meta tag in index.html's <head> is the actual authoritative
# "keep this out of search" signal Google honors; this Disallow is a
# second layer on top of it, safe here specifically because this build
# has no existing backlinks yet to trigger the usual "indexed with no
# snippet" edge case a robots.txt-only block can cause elsewhere.
# Remove this Disallow and the noindex meta tag together, at the same
# time, when this build is ready to be found publicly.
User-agent: *
Disallow: /
