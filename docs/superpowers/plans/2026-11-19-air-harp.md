# Air Harp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A subscribers-only game where kids build a harp of up to 8 strings with two-hand pinches and play it by strumming in the air.

**Architecture:** One self-contained HTML file (`supabase/private-games/air-harp.html`) in the Hands-Free Builder style. A `/* AH:PURE */ ... /* /AH:PURE */` block holds the pure rules (pitch, loudness, hits), which the test extracts with `new Function`. Audio is Web Audio (embedded harp PCM + Karplus-Strong guitar), drawing is one 2D canvas.

**Tech Stack:** Plain JS, Canvas 2D, Web Audio, MediaPipe Hands 0.4.1675469240 (same pin as Builder), vitest.

**Spec:** docs/superpowers/specs/2026-11-19-air-harp-design.md

## Global Constraints
- Max 8 strings. Scale: C major pentatonic, MIDI 48..84 (C3..C6). Raw pitch `84 - 12*log2(len/shortest)`, shortest = 0.08 x stage diagonal.
- Slow strum soft, fast strum loud (and a little brighter). Ripples soft and translucent, in the string's color.
- Video never shown; camera through the site relay (`ccsCamera` messages), direct camera when opened alone.
- Dark by default; no emojis; no em dashes in copy; logo loading screen (`ccsLoad`, data-name "Air Harp").
- Commit with explicit file lists. Never publish, push or email without the owner's word.

## Review Focus
1. A hand lost mid-pinch (out of frame) must end the pinch cleanly: no string stuck to a ghost hand.
2. Two strings crossing one fingertip move in a single frame both pluck, each once (per-string cooldown 90 ms).
3. Resizing a string to under the minimum length keeps it at the minimum (never a zero-length string).
4. Audio must start only after a user gesture (AudioContext resumed on the first click/tap or camera start).
5. Mouse and hands at once (camera on, mouse used) must not fight over the same ball.

### Task 1: The rules (pure block + tests)
**Files:** Create `supabase/private-games/air-harp.html` (pure block only at first), Test `test/airHarp.test.js`
**Produces:** `MAX_STRINGS=8`, `SCALE` (array of MIDI 48..84 pentatonic), `rawMidi(len, diag)`, `noteFor(len, diag)` -> MIDI in SCALE, `noteName(midi)` -> "C4", `loudness(speed, diag)` -> 0.12..1 (speed px/s; 0.25 diag/s soft, 3 diag/s loud), `crosses(p0, p1, a, b)` -> bool, `nearestBall(strings, x, y, r)` -> `{ i, end }|null`, `minLen(diag)`, `isFling(vx, vy, diag)` -> bool (speed > 2.4 diag/s), `colorFor(midi)` -> hex along pink, amber, green, sky, violet.
- [ ] Tests: lengths map longer -> lower; every result is in SCALE; shortest -> 84, very long -> 48; loudness monotonic, clamped; crosses true for X shapes, false for parallel/apart; nearestBall picks the closer end within r; fling threshold; MAX_STRINGS 8.
- [ ] Run: `npx vitest run test/airHarp.test.js` (fail), implement, pass, commit.

### Task 2: Screen, sound and play
**Files:** Modify `supabase/private-games/air-harp.html`; Create `scripts/air-harp-samples.mjs` (writes `concert-harp/40,56,71,87.wav` PCM as base64 between `/*HARP:*/` markers); extend `test/airHarp.test.js`.
- [ ] Tests (structure): loader with `data-name="Air Harp"`; `maxNumHands:2`; `ccsCamera:"start"` relay; never `drawImage` of the video onto a visible canvas; `HARP_SAMPLES` has keys 40, 56, 71, 87; Harp/Guitar switch; "/ 8 strings" counter; no emojis.
- [ ] Build from the approved draft: layout, gesture list (Make, Move, Play, Remove), "Longer is lower" card, Chike (CHIKE_POSES from Builder), start overlay, theme toggle, Clear.
- [ ] Sound: harp = nearest sample, `playbackRate = 2^((midi-base)/12)`, lowpass by loudness; guitar = Karplus-Strong buffer cached per MIDI; light reverb; master compressor.
- [ ] Hands: per hand pinch with hysteresis (on < 0.32 palm, off > 0.45), pinch point = mid of points 4 and 8, stage mapping from the camera's middle box; both pinching in empty space -> new string; pinch near ball -> move that end (pitch live); release fast -> fling removes; open hand pointer tip path crossing a string -> pluck with `loudness`.
- [ ] Mouse/touch: press empty + drag = new string; press ball = move/drag off to remove; press on/near string + drag = strum.
- [ ] Visuals: vibration (decaying, slower for low notes), soft ripple capsules in the string color sized by loudness, ball states, note labels, hand markers, both digital hands in the panel.
- [ ] Run all tests; check in the browser with the mouse; commit.
