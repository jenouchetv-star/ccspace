# Solar System Sandbox: image sources

All maps are NASA imagery in the public domain (no credit line required). Resized and re-saved as JPEG on 2026-11-14.

| File | Source | Changes |
|---|---|---|

| mars.jpg | NASA 3D Resources, Images and Textures/Mars (github.com/nasa/NASA-3D-Resources), "free and without copyright" | none |

| saturn.jpg | NASA 3D Resources, Images and Textures/Saturn | colour saturation lowered to 55% to match Saturn's pale tone |
| neptune.jpg | NASA 3D Resources, Images and Textures/Neptune | none |
